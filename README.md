# Librify 📖

O **Librify** é uma plataforma web de biblioteca virtual e acadêmica projetada para conectar leitores, automatizar processos de reservas de livros e permitir que usuários publiquem suas próprias obras para moderação. 

Este software foi desenvolvido como parte de um **Projeto de Extensão da Universidade de Fortaleza (UNIFOR)**, integrando conceitos práticos de Engenharia de Software, Arquitetura de Sistemas e Desenvolvimento Web.

## Funcionalidades Principais (Escopo)

O sistema foi totalmente modelado via UML (Casos de Uso e Diagramas de Atividades) e implementado com base em 21 Requisitos Funcionais, destacando-se:
* **Autenticação Segura (RF01 - RF03):** Controle de acesso com criptografia de senhas (hash) e fluxo de recuperação.
* **Catálogo e Detalhes (RF07 - RF08):** Busca inteligente de obras por título ou autor, filtros por categoria e sistema de reservas.
* **Avaliação de Livros (RF09):** Sistema de feedback com notas de 1 a 5 estrelas e comentários de usuários.
* **Publicação Colaborativa (RF12 - RF13):** Upload de arquivos em PDF pelos alunos para a fila de moderação.
* **Painel Administrativo (RF18 - RF21):** Telas exclusivas para o administrador gerenciar o acervo, aprovar/rejeitar publicações e definir o "Livro do Mês".
